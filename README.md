# RugCharts

Real-time crypto token charting and TA. Part of [RMI (Rug Munch Intelligence)](https://github.com/Rug-Munch-Media-LLC/rugmuncher-backend) — the first open-source crypto intelligence platform.

Built by [Rug Munch Media LLC](https://rugmunch.io), a Wyoming-based software company.

---

## What it does

RugCharts is the charting and visual analysis layer of the RMI platform:

- **Real-time OHLCV** — across 7+ chains, 2500+ assets
- **AI TA bot** — auto-detects patterns, support/resistance, divergences
- **Live trade streaming** — see order flow as it happens
- **Liquidity heatmaps** — visualize where the orders are
- **x402 paid tools** — premium indicators, paid via micropayment

## Quick start

```bash
npm install
cp .env.example .env
npm run dev
```

## Tech stack

- TradingView Lightweight Charts for rendering
- React 19 + Vite
- WebSocket streaming from RMI backend
